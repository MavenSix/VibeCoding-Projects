# Advocacy Builder - Project Roadmap

Interactive project roadmap and strategic planning tool for the Workday Advocacy Builder product.

## Features

- **Project Overview**: Value propositions, core capabilities, and 6 strategic proof point categories
- **Interactive Roadmap**: 5-phase timeline with expandable artifacts and progress tracking
- **Work Breakdown Structure**: 6 workstream buckets with effort/priority indicators
- **Action Items Tracker**: VML action items and stakeholder directory

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS (Workday brand colors)
- shadcn/ui components
- motion.dev animations

## Getting Started

```bash
npm install
npm run dev
```
